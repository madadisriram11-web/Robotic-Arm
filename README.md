This porject is a 4-axis Robotic Arm. It has 4 motors: 1 for the turning, one for the shoulder, one for the bicep, and one for the claw. It has a very small claw, so it is more for show than for functionality. It is connected to a simple Arduino Elegoo Uno and will be controlled by 2 joysticks.
